# Medium publishing checklist

Use after the article and results have been reviewed.

- [ ] Create or open a Medium draft.
- [ ] Copy cleaned article text section by section.
- [ ] Format the title and subheaders.
- [ ] Use Medium code blocks for short snippets and inline code for variable names.
- [ ] Keep the article readable; link to the full reproducible implementation instead of making a code dump.
- [ ] Upload exported PNG charts; add captions and alt text.
- [ ] Link prominently to the GitHub repository once published.
- [ ] Optionally embed a GitHub Gist for longer examples.
- [ ] Render important equations as clear images if needed.
- [ ] Add appropriate Medium topics.
- [ ] Preview before publishing.
- [ ] Verify all links and figures after publication.
